# 모바일 청첩장

심플 · 블랙 & 옐로우 포인트 모바일 청첩장. 빌드 과정 없이 `index.html` 파일 하나로 동작합니다.

## 내용 수정하기

`index.html`을 열어 `★ 여기만 수정하면 됩니다` 라고 표시된 `CONFIG` 부분만 고치면 됩니다.

| 항목 | 위치 |
|---|---|
| 신랑·신부 이름, 혼주(부모님), 소개 문구 | `groom` / `bride` |
| 예식 날짜·시간 | `date` |
| 예식장 이름·주소·전화·좌표 | `venue` |
| 초대 인사말 | `inviteMessage` |
| 대중교통·주차 안내 | `transport` |
| 축의금 계좌 (신랑측/신부측) | `accounts` |
| 유튜브 영상 | `youtubeId` (주소의 `v=` 뒤 ID만) |
| 축하 사진 공유 앨범 | `shareAlbumUrl` |

### 좌표 찾는 법
네이버지도에서 예식장 검색 → 주소 우클릭(모바일은 길게 누르기) → 좌표 복사 → `venue.lat`(위도), `venue.lng`(경도)에 입력. 네비게이션 버튼 3개(네이버지도/티맵/카카오내비)가 이 좌표를 사용합니다.

## 사진 넣기

`images/` 폴더에 아래 이름으로 넣으면 됩니다. (없으면 회색 플레이스홀더가 표시됩니다)

- `main.jpg` — 첫 화면 풀스크린 사진 (세로형 권장, 1080×1920 내외)
- `groom.jpg`, `bride.jpg` — 소개 섹션 프로필 사진
- `gallery1.jpg` ~ `gallery9.jpg` — 갤러리 (CONFIG에서 개수 조절 가능)
- `map.jpg` — 약도 이미지 (예비용). 오시는 길에는 실제 동작하는 지도가 뜨고, 지도 스크립트를 못 받아올 때만 이 이미지가 대신 보입니다

사진은 3MB 이하로 압축하면 로딩이 빨라집니다 (squoosh.app 추천).

## 축하 사진 공유 앨범 만들기

1. 구글 포토 → 앨범 생성 → 옵션에서 "공동작업" 켜기
2. "링크로 공유" 주소 복사 → `CONFIG.shareAlbumUrl`에 붙여넣기

## 배포하기 (무료)

- **GitHub Pages**: 저장소에 올리고 Settings → Pages 활성화
- **Netlify**: netlify.com에서 폴더를 드래그 앤 드롭하면 끝

배포 후 카카오톡 공유 미리보기를 위해 `index.html` 상단 `og:image`를 실제 배포 주소 기준 경로로 바꿔주세요.
